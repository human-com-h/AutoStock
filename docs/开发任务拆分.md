# AutoStock 开发任务拆分（Task Breakdown）

依据《系统设计说明书》第 15 节的三阶段划分展开。每个任务给出 ID、内容、交付物/验收标准、依赖关系，便于按序认领。带 [手动] 的任务需要真机或人工操作，不能只靠自动化测试判定完成。

## 任务认领建议

- 按 ID 顺序做，阶段内任务尽量按依赖列顺序推进；同一阶段内没有依赖关系的任务（如 1.1.x 各主数据模块）可并行。
- 每完成一个任务，用 `reconcile`（见 docs/推荐Skill列表.md）跑一次对账，尽早发现库存计算类任务引入的偏差，而不是留到阶段验收才发现。
- 标 [手动] / [需真机] 的任务不要指望自动化测试覆盖，需要提前安排真机与人工验证时间。
