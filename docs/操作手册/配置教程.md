# AutoStock PC + Android 配置教程

当前推荐架构：

- PC 是数据中心，必须运行 AutoStock。
- 手机和 PC 在同一局域网时才能配对、初始化和同步。
- 手机外出时可以离线查库存、开单；回到同一 WiFi 后同步。
- 不需要云服务器，没有额外服务费用。
- 不要在路由器上做公网端口映射。

## 一、PC 端配置

### 1. 固定 PC 的局域网 IP

建议在路由器管理页面设置“DHCP 地址保留”，将 PC 固定为例如：

```
192.168.1.100
```

在 PC 上查看当前地址：

```
ipconfig
```

找到当前 WiFi 或以太网适配器的“IPv4 地址”。

固定 IP 很重要：如果 IP 改变，手机主屏幕中保存的旧地址将无法连接，需要用新地址重新打开。

### 2. 重新生成最新版 EXE

当前已有的 `release\AutoStock.exe` 生成时间早于阶段三最终修改，建议先重新打包：

```
cd E:\AutoStock
.\backend\.venv\Scripts\python.exe scripts\package_windows.py
```

完成后运行：

```
.\release\AutoStock.exe
```

程序会自动：

- 迁移数据库；
- 生成本地 CA 和 HTTPS 证书；
- 启动 HTTPS 端口 `8756`；
- 启动证书下载端口 `8757`；
- 打开 PC 管理页面。

PC 页面地址：

```
https://127.0.0.1:8756
```

### 3. 不打包，直接从源码运行

开发环境也可以这样启动：

```
cd E:\AutoStock
pnpm.cmd install
.\backend\.venv\Scripts\python.exe scripts\build_web.py
cd backend
.\.venv\Scripts\python.exe run_web.py
```

不要使用普通的无证书 `uvicorn` 命令作为正式手机访问方式，因为手机 PWA 需要 HTTPS。

### 4. 允许 Windows 防火墙访问

第一次启动时，如果 Windows 弹出防火墙提示：

- 允许访问；
- 只勾选“专用网络”；
- 不建议开放“公用网络”。

如果没有弹窗，以管理员身份运行 PowerShell：

```
New-NetFirewallRule -DisplayName "AutoStock LAN" `
  -Direction Inbound `
  -Action Allow `
  -Protocol TCP `
  -LocalPort 8756,8757 `
  -Profile Private
```

检查端口：

```
Get-NetTCPConnection -LocalPort 8756,8757 -State Listen
```

### 5. PC 浏览器信任证书

证书位置：

```
%APPDATA%\AutoStock\certs\ca.crt
```

双击 `ca.crt`，依次选择：

1. 安装证书；
2. 当前用户；
3. 将所有证书放入下列存储；
4. 受信任的根证书颁发机构；
5. 完成。

重新打开浏览器后访问：

```
https://127.0.0.1:8756
```

绝对不要复制或分享：

```
%APPDATA%\AutoStock\certs\ca.key
```

### 6. PC 端首次设置

进入“系统设置”后建议完成：

- 设置店铺名称；
- 设置默认单位；
- 确认是否允许负库存；
- 设置登录密码；
- 创建一次初始备份。

数据库默认位置：

```
%APPDATA%\AutoStock\autostock.db
```

备份目录：

```
%APPDATA%\AutoStock\backups
```

## 二、Android 手机配置

目前手机端按项目设计仅正式支持 Android。

### 1. 连接同一 WiFi

确认：

- PC 和手机连接同一个路由器；
- 手机没有使用访客 WiFi；
- 路由器没有开启“AP 隔离/客户端隔离”；
- 暂时关闭手机 VPN；
- PC 上 AutoStock 正在运行。

### 2. 下载本地 CA 证书

假设 PC 固定 IP 为 `192.168.1.100`，在手机 Chrome 打开：

```
http://192.168.1.100:8757/ca.crt
```

注意这里下载证书使用的是 `http` 和端口 `8757`。

### 3. 安装 CA 证书

Android 常见路径：

```
设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书
```

不同品牌手机路径可能略有不同，可以直接在系统设置中搜索：

```
CA 证书
```

或者：

```
安装证书
```

选择刚下载的 `ca.crt`，证书名称应显示为：

```
AutoStock Local CA
```

Android 提示“网络可能会被监控”属于安装用户 CA 后的正常系统提示。

安装后彻底关闭并重新打开 Chrome。

### 4. 在 PC 生成配对码

PC 页面进入：

```
系统设置 → 手机配对
```

点击“生成配对二维码”。

配对码有效期为 **5 分钟**。

同时确认 PC 和手机时间均开启“自动设置时间”，两者时间差不能超过 2 分钟。

### 5. 手机打开配对页面

使用系统相机扫描 PC 上的二维码。

也可以手动打开：

```
https://192.168.1.100:8756/m/#/setup
```

然后：

1. 点击“安装好了，检测一下”；
2. 显示“HTTPS 已连接”；
3. 填写设备名称，例如“仓库手机”；
4. 输入 PC 上的六位配对码；
5. 点击“配对并初始化”；
6. 等待零件、库存和近 90 天单据初始化完成。

首次初始化过程中不要关闭页面或切换网络。

### 6. 添加到手机主屏幕

初始化完成后，在 Chrome 中选择：

```
菜单 → 添加到主屏幕
```

以后从 AutoStock 桌面图标打开。

不要清除 Chrome 中该站点的数据，否则手机本地库存、离线队列和配对令牌会被清除，需要重新配对。

## 三、日常同步方式

### 手机与 PC 在同一 WiFi

系统会在以下时机尝试同步：

- 手机应用启动；
- 网络连接恢复；
- 定时静默同步；
- 手动点击同步。

手动同步路径：

```
手机端 → 我的 → 同步中心 → 一键同步
```

PC 可在以下位置查看结果：

```
PC 端 → 设备与同步
```

这里可以查看：

- 已配对设备；
- 最近同步时间；
- 同步历史；
- 冲突复核；
- 启用或停用设备。

### 手机在外面或使用移动流量

这时无法连接 PC，但仍然可以：

- 查询已初始化的零件；
- 查看本地库存；
- 快速入库；
- 快速出库；
- 查看手机本地记录。

新单据会显示为“待同步”。

回到 PC 所在 WiFi 后，打开应用并进入同步中心执行一次同步即可。

## 四、常见问题

### 手机打不开证书下载地址

检查：

- PC 程序是否运行；
- IP 地址是否正确；
- 手机是否连接同一 WiFi；
- Windows 网络是否设置为“专用网络”；
- 防火墙是否允许 8756、8757；
- 路由器是否启用了设备隔离。

### 证书下载成功，但 HTTPS 检测失败

检查：

- CA 是否安装到“CA 证书”，而不是“VPN 和应用证书”；
- 是否重新启动 Chrome；
- 地址是否使用 `https://PC-IP:8756`；
- PC IP 是否发生变化。

### 扫描二维码打不开

二维码可能选择了虚拟网卡或 VPN 地址。运行：

```
ipconfig
```

找到实际 WiFi IPv4，然后在手机手动打开：

```
https://实际IP:8756/m/#/setup
```

再手动输入六位配对码。

### 配对码无效

- 配对码只有 5 分钟有效期；
- 重新生成一个；
- 确保手机和 PC 自动校时；
- 两者时间差不得超过 2 分钟。

### 回到 WiFi 后仍无法同步

检查：

- PC 服务是否运行；
- 手机是否连接正确的 WiFi；
- “设备与同步”中该手机是否被停用；
- 手机同步中心是否显示待同步记录；
- PC IP 是否改变。
